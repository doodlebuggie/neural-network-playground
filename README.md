# neural-network-playground

A personal project for learning artificial neural networks
from the mathematical foundations to practical PyTorch models.

## Goals

- Understand artificial neurons
- Implement a neural network using NumPy
- Understand forward propagation
- Understand backpropagation
- Understand gradient descent
- Reimplement the network using PyTorch
- Investigate hyperparameters
- Compare MLPs and CNNs

## Technologies

- Python
- NumPy
- PyTorch
- Matplotlib
- scikit-learn

## Project progression

1. NumPy neural network
2. PyTorch neural network
3. MNIST classification
4. Hyperparameter experiments
5. CNN
6. MLP vs CNN comparison
